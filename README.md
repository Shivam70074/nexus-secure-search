# NEXUS Secure Search 2.0

AI-powered developer community discovery and secure messaging platform built on three core pillars:
1. Zero-Trust Cybersecurity (AI-Native WAF + SafeQueryBuilder)
2. Blockchain Threat Ledger (Cryptographic SHA-256 immutable audit trail)
3. Post-Quantum Cryptography (NIST FIPS 203 ML-KEM-512)

## Setup Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```

## Setup Frontend
```bash
cd frontend
npm install
npm run dev
```
